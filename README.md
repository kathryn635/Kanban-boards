# 📋 Kanban Task Management

Интерактивная Kanban-доска для управления задачами. Построена на React, TypeScript и Vite.

## 🚀 Быстрый старт

 Установка
npm install
npm run dev
 Возможности
  Колонки задач
Backlog — пул новых задач

Pending — ожидают своей очереди

To Do — запланированы к выполнению

Doing — в активной работе

Done — успешно завершены

✨ Что можно делать с задачами
➕ Создавать задачи: заголовок, описание, приоритет, теги, изображение

🖱 Перетаскивать между колонками (Drag & Drop)

🗑 Удалять ненужные задачи

🔍 Искать задачи через поисковую строку

🏷 Добавлять цветные теги (цвета подбираются автоматически)

🎯 Назначать приоритет: низкий, средний, высокий

📎 Прикреплять изображения

📊 Видеть количество задач в каждой колонке

💾 Автосохранение
Все данные автоматически сохраняются в localStorage. vsdabfbhfsebhfsdbb fdbfdsbbd
